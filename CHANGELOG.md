# Changelog

## 0.1.0

Initial sellable MVP for Databricks migration assessment and planning.

Included:

- Databricks Asset Bundle with assessment, target demo and semantic prep jobs.
- Metadata landing flow for demo and customer artifacts.
- Delta outputs for control, bronze, silver, gold and demo layers.
- Local SQL Server fixture and export flow.
- Neo4j graph publishing and verification.
- Databricks Vector Search index creation and querying.
- RAG retrieval, Foundation Model answer generation and MLflow logging.
- Starter RAG evaluation harness.
- Customer implementation, architecture, advanced capabilities, demo and packaging documentation.

Known customer-dependent extensions:

- Customer-specific extractors for real-world ADF, Synapse, SQL Server, notebook and SQL patterns.
- Customer-specific scoring weights and migration wave rules.
- Customer-specific service principals, secret scopes, CI/CD and deployment approvals.
- Optional Model Serving or AI Gateway assistant endpoint.
